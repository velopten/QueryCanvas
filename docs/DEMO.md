# 데모 시나리오

기본 도메인 팩(commerce)으로 5분 안에 전체 기능을 보여주는 순서입니다.

```bash
cd backend && uvicorn main:app --port 8008
cd frontend && npm run dev                     # http://localhost:5173
```

mock 데이터는 실행일 기준 최근 12개월로 자동 생성되므로 별도 준비가 필요 없습니다.

## 1. 기본 플로우

**질문**: `최근 3개월 카테고리별 매출 비중 보여줘`

- 파이프라인 단계가 실시간으로 표시됩니다: 캐시 조회 → RAG 검색 → SQL 생성 → 검증 → 실행 → UI 생성
- 화면 골격이 먼저 뜨고, 데이터와 차트가 순서대로 채워집니다
- 같은 질문을 다시 하면 캐시 히트로 SQL 생성 단계가 생략됩니다

## 2. 추세 읽기

**질문**: `뷰티 카테고리 매출이 요즘 늘고 있는지 월별로 보여줘`

- 에이전트가 가상 view를 선택하고, 시스템이 실행 직전에 실제 SQL로 치환합니다
- mock 데이터에 심어둔 뷰티 카테고리 성장세가 라인 차트로 드러납니다
- 브리핑 카드는 수치 팩트만 요약합니다

## 3. 동명이인 처리

**질문**: `김민준의 최근 3개월 주문 내역 보여줘`

- 에이전트가 같은 이름의 고객 2명을 스스로 찾아냅니다
- 확정 전에 SQL을 시험 실행해 스스로 검증합니다
- 결과 표에 고객 ID와 지역이 함께 나와 두 사람이 구분됩니다
- 개인정보 컬럼은 매핑 키로 대체되어 LLM에 노출되지 않습니다

이어서 표에서 이름 셀을 클릭하면 입력창에 `C0001(김민준)의` 가 자동으로 들어가고, 뒤에 이어서 물으면 ID 기준으로 다시 조회합니다.

## 4. 꼬리질문

3번 결과 화면에서 그대로 물어봅니다: `이 중에 취소된 건 몇 건이야?`

새 SQL 없이 현재 화면의 데이터만으로 텍스트 답변이 나옵니다.

## 5. 화면 저장

마음에 드는 화면을 이름 붙여 저장하면 사이드바 "내 화면"에 메뉴로 등록됩니다. 다시 열면 SQL만 재실행되고 저장된 화면 구성이 그대로 재사용됩니다. 저장 시 "이번 달" 같은 표현이 상대 표현으로 유지되므로 다음 달에도 유효합니다.

## 6. 관리자 콘솔

`/admin` 으로 이동합니다.

- **평가**: 골든셋 실행, 이력 조회, 실행 2건 나란히 비교
- **파이프라인 추적**: 단계별 프롬프트/토큰/비용/도구 호출 기록
- **학습 데이터**: 자유 텍스트를 입력하면 AI가 저장 방식과 위치를 판단
- **검색 가중치**: RAG 타입별 가중치 조정
