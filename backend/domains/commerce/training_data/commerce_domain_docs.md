# 커머스 도메인 지식

## 매출의 정의
매출 = 주문 품목 금액(TB_ORDER_ITEM.AMOUNT)의 합. AMOUNT는 단가×수량이 이미 계산된 값(원).
**취소(STATUS='04')와 반품(STATUS='05') 주문은 매출에서 제외**한다 — STATUS NOT IN ('04','05').
단, "취소/반품 현황"을 직접 묻는 질문은 해당 상태를 조회 대상으로 한다.

## 반품률
반품률 = 반품 주문수(STATUS='05') / 전체 주문수. 분모·분자의 기간과 그룹 기준을 동일하게.
반품은 구매확정 이후 발생하므로 최근 1주일 주문에는 거의 없다 — 반품률 분석은
최소 1개월 이상 기간으로 보는 것이 적절하다.

## 주문 상태 흐름
주문접수(01) → 배송중(02) → 구매확정(03). 취소(04)는 배송 전, 반품(05)은 구매확정 후 발생.
"완료된 주문"은 구매확정(03)을 의미한다.

## 고객 등급
VIP(01)는 전체의 약 10%지만 주문 비중이 높다. 등급별 분석 시 GRADE 코드를
TB_CODE(GRP_CD='GRADE')로 한글명 변환해 표시한다.

## 동명이인 고객
고객명은 유일하지 않다 (예: 김민준 2명, 이서연 2명). 이름으로 필터할 때는
CUST_ID를 함께 SELECT하고, 특정인을 지목해야 하면 지역/등급으로 구분하거나
후보 확인 도구를 사용한다.

## 채널
웹(01)/앱(02)/오프라인(03). 앱 주문 비중이 지난 1년간 꾸준히 증가하는 추세다.
